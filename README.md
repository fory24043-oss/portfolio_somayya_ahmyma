#  Pinky Recipes

##  Description du projet
Pinky Recipes est une application web interactive qui permet de découvrir différentes recettes de gâteaux.

L’utilisateur peut se connecter via une page de login, consulter une galerie de recettes et afficher les détails complets de chaque recette en cliquant dessus.

Ce projet a été réalisé en utilisant HTML, CSS et JavaScript afin de pratiquer la création d’interfaces web dynamiques et la manipulation du DOM.



##  Fonctionnalités
-  Page de login avec validation des champs
-  Galerie de recettes sous forme de cartes
-  Affichage des détails de chaque recette
-  Bouton pour revenir à la liste des recettes
-  Bouton pour rechercher des idées de gâteaux sur Google
-  Interface simple et interactive



## Technologies utilisées
- HTML
- CSS
- JavaScript
